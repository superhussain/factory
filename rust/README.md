# factory, in Rust

`rust/factory` is a port of `skills/factory/runtime/factory.py`. Python stays the oracle: the parity harness runs each case on both and compares exit code, stdout, stderr, the home tree, tool calls and Worker requests (see `docs/development.md`, Parity harness). The binary is not installed or called by the skill yet.

```sh
cd rust && cargo build --release --locked && cargo test --locked
python3 tests/parity/run.py --bin rust/target/release/factory --ids rust/parity
```

## Module contract

All paths are under `rust/factory/src/`. `shared` is the core every command uses. It is not named `core`, which would collide with Rust's built-in crate.

| File | Public items |
| --- | --- |
| `main.rs` | `fn main()`: runs `cli::main` on the arguments, flushes stdout, exits with its code |
| `cli.rs` | `Call { args, agents, connection }`, `Handler = fn(&Call) -> Res<()>`, `COMMANDS` (name, handler, min and max operands, in `factory.py` order), `USAGE`, `main(args) -> i32`, `not_ported(name) -> Exit` |
| `shared/exit.rs` | `Exit { code, stderr, status }`, `Res<T>`, `fail(msg, code)`, `exit(code)`, `Exit::raw(code, stderr)`, codes `USAGE_ERROR` 2 through `HUMAN` 7 |
| `shared/py.rs` | `repr`, `is_printable`, `printable_line`, `is_space`, `strip`, `lstrip`, `rstrip`, `splitlines`, `universal_newlines`, `os_error`, `round_half_even`, `round_int` |
| `shared/unicode_printable.rs` | `NON_PRINTABLE` ranges, generated by `rust/tools/gen_printable.py` |
| `shared/unicode.rs` | `nfkc(s)`: a per-character NFKC fold from the table `rust/tools/gen_nfkc.py` writes to `nfkc_table.rs` |
| `shared/pyjson.rs` | `Style` and `DEFAULT`, `INDENT2`, `INDENT2_SORTED`, `SORTED`, `NO_ASCII`, `COMPACT`; `dumps`, `float_repr`, `loads` |
| `shared/pyre.rs` | `Flags` (`NONE`, `ASCII`, `I`, `M`, `S`), `Pattern::new` with `search`, `match_start`, `fullmatch`, `is_full`, `find_iter`, `replace_all`; `translate`; `Captures` |
| `shared/consts.rs` | every module constant of `factory.py` from `SLUG` to `BACKLOG_TEMPLATE`, plus `tag_lookalike(c)` |
| `shared/fs.rs` | `read_text`, `write_atomic`, `seed`, `mkdir_private`, `is_link`, `regular_metadata`, `readable`, `listable`, `resolve`, `same_path` |
| `shared/conf.rs` | `unquote`, `Conf`, `read_conf`, `read_env_ordered`, `frontmatter`, `fm_get`, `closed_frontmatter` |
| `shared/time.rs` | `unix_now`, `format_stamp`, `now`, `parse_stamp`, `elapsed_seconds` |
| `shared/proc.rs` | `Out`, `capture`, `run`, `git`, `git_ok`, `origin_git`, `paseo_run`, `which`, `hostname` |
| `shared/home.rs` | `set_override`, `config_root`, `resolve_home`, `factory_home`, `read_location`, `validate_home`, `device_name`, `holder`, `skill_root` |
| `shared/http.rs` | `Response` with `header` and `text`; `normalized_origin`, `endpoint_message`, `token_message`, `access_message`, `api_url`, `quote`, `api`, `cas`, `urlopen_error` |
| `shared/board.rs` | `load_board`, `dump_board`, `read_board`, `merge_patch`, `patch_job`, `lead_of`, `batch_refs`, `riders_of`, `mirror_batch`, `unchanged`, `escalated` |
| `shared/project.rs` | `r2_target`, `project_files`, `strong`, `project_etag`, `sha`, `local_bytes`, `read_project_state`, `save_project_state`, `pull_project`, `read_paths`, `safe_job_folder` |
| `commands/lookup.rs` | `where_cmd`, `job`, `builds`, plus `main_checkout` and `remotes` for other slices |

- Board data stays `serde_json::Value` with `preserve_order` and `arbitrary_precision`, so unknown fields and big numbers round-trip.
- Regexes and the HTTP agent are `OnceLock` statics, compiled or built on first use.
- `api` keeps one blocking `ureq` agent per process, sends `User-Agent: factory` and the `.env` Access headers, and caches `READ_CACHED` GETs for 60 seconds.

A handler keeps the Python function's name, except `where`, which is `where_cmd`. An unported handler returns `Err(not_ported(name))`, which exits 2 with `factory.py: <name> is not ported to the Rust binary yet`.

## Porting rules

| Python | Rust |
| --- | --- |
| `fail(msg, 4)` | `return Err(fail(msg, 4))` |
| `sys.exit(3)` | `return Err(exit(3))` |
| `ApiStatusExit` | `Exit` with `status: Some((code, detail))` |
| `redirect_stderr` plus `except SystemExit` | `match` on `Err(e)`, dropping `e.stderr` |

- `cli::main` prints `e.stderr` once and exits with `e.code`. No panic is used for control flow.
- A slice edits only its own command file, its `tests/parity/cases/<prefix>.json` and its `rust/parity/<prefix>.txt`. It adds no dependency.
- A shared helper the slice needs but `shared` lacks becomes a private function in the slice's own file. A bug in `shared` gets its own small PR into `rust`.
- Port line for line, keeping Python's statement order wherever bytes on disk, the board or the wire are compared.

## Known divergences

- Python tracebacks are not reproduced. Where Python raises uncaught, Rust fails 1 with `factory.py: <what>`. No parity case covers a traceback.
- Non-UTF-8 argv fails 2. Invalid UTF-8 in subprocess output is decoded lossily, where Python would raise.
- `serde_json` refuses `NaN` and `Infinity` in JSON input. Python accepts them. The Worker never writes them.
- A lone surrogate escape (`\ud800` without its pair) in JSON input is dropped before parsing, since a Rust string cannot hold one. Python keeps it in the string, and its inbox output drops it too.
- On Windows a job id ending in `.` is refused as a bad target, since Windows drops a trailing dot from a folder name. Python accepts it.
- A regex search that passes 100 million backtracking steps counts as no match and prints one warning, where Python's `re` keeps going. A substitution that hits the backtrack limit exits 1 instead, so unredacted text is never written.
- A response body over 64 MiB fails the request, where Python reads any size.
- Unicode `\w` is `[\p{L}\p{N}_]`. That is close to `str.isalnum`, not identical, and the Unicode versions differ between the `regex` crate and the Python in use.
- `parse_stamp` reads ASCII digits only, where `strptime` also takes other Unicode decimal digits.
- `nfkc` folds one character at a time, so it skips composition across characters. A check that rejects folded text can only over-reject compared with full NFKC.
- A Worker body that is not UTF-8 fails 1 with `the Worker sent a body that is not UTF-8`. Python fails 5 with `can't reach {url}: 'utf-8' codec ...`.
- TLS error text and Windows OS error text differ from Python's.
- HTTP header names go out in lowercase (`http` crate). Python sends `User-agent` style. Python also sends `Accept-Encoding: identity` and `Connection: close`.
